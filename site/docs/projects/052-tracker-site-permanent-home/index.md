## Description

The public project tracker currently lives at `https://aburnsy.github.io/tidytowns/` — a personal GitHub Pages preview URL that was set up while the site was still a work in progress. The site has now grown into a real village asset (the formal multi-year plan, the village map, project pages, the heritage section), and a personal-account host is no longer the right long-term home.

2027 is the year we settle that. The 2026 application is in with the current URL printed on the map and in the cover, so the clean window is after the 2026 result is known and before the 2027 cycle begins. By then we'll also have a year of practical experience to know what the format is genuinely worth keeping versus tidying up.

## Three things to settle

### a) A formalised URL, with funding agreed if needed

Register a short domain (something like `tmbtidytowns.ie`) and point GitHub Pages at it. Hosting on GitHub Pages stays free, but the domain itself costs a small annual fee that the committee would commit to covering. Keeps the site as a focused TidyTowns asset with a clean address that's easy to print on signage and on committee material.

### b) Or: incorporate elements into the main `tmbvillage.com` site

The Development Group already runs the village website. A "TidyTowns" section over there would consolidate village comms in one place and ride on the brand residents already know. This needs a Development Group conversation about scope and ownership — full move, partial integration, or just cross-linking — and is the right call if their site is the natural front door.

### c) Offer the project-tracking format to other village groups

The format itself — public project pages with status, cost, benefit and an honest narrative — has worked well for us. If other village groups would find it useful for their own work (the Development Group, the parish, the school, the sports clubs, anyone else), we'd be happy to help them set up the same thing. Not a push, just an open offer; it's there if anyone wants it.

## What needs to happen

- Decide between routes (a) and (b) — committee + Development Group conversation.
- If (a): register the domain, configure GitHub Pages, set the old `aburnsy.github.io/tidytowns/` URL to redirect so links printed in 2026 application material stay live, and sweep the codebase for any hard-coded references (village map PDF banner, application docs).
- If (b): scope what moves and what stays, agree ownership and editing workflow with the Development Group.
- For (c): a quiet conversation with each of the other village groups when the time is right, no pressure either way.

## Why 2027

The 2026 application has just gone in with the current URL printed on the map and in the cover; making the move mid-cycle would invalidate links the adjudicator may follow. A year of running the site as-is also gives us an honest read on which parts are genuinely useful and which can be trimmed before the move.
