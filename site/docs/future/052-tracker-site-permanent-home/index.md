## Description

The public project tracker currently lives at `https://aburnsy.github.io/tidytowns/` — a personal GitHub Pages preview URL that was set up while the site was still a work in progress. The site has now grown into a real village asset (the formal multi-year plan, the village map, project pages, the heritage section), and a personal-account host is no longer the right long-term home.

This is deliberately parked as a 2027 piece. The site still has rough edges and the address change is a job worth doing once, properly, when the rest of the content has settled.

## Two viable routes

1. **Dedicated TidyTowns URL.** Register a short domain (something like `tmbtidytowns.ie` or a subdomain on `tmbvillage.com`) and point GitHub Pages at it. Keeps the site as a focused TidyTowns asset with a clean address that's easy to remember and easy to print on signage and committee material.
2. **Fold into the existing village website at `tmbvillage.com`.** The Development Group already runs the village website. A "TidyTowns" section over there would consolidate village comms in one place and ride on the brand residents already know.

The committee's preference is not yet decided; the right answer depends partly on how the village website itself evolves over the next year.

## What needs to happen

- Decide between the two routes (committee + Development Group conversation).
- Register the domain or set up the subdomain on `tmbvillage.com`.
- Configure GitHub Pages (or the Development Group's host) to serve the existing site at the new address.
- Set the old `aburnsy.github.io/tidytowns/` URL to redirect, so links printed in the 2026 application stay live.
- Sweep the codebase for any hard-coded `aburnsy.github.io` references and update them (village map PDF banner, application docs, etc.).

## Why not now

The 2026 application has just gone in with the current URL printed on the map and in the cover. Making the move mid-application cycle would invalidate links the adjudicator may follow. The clean window is after the 2026 result is known and before the 2027 cycle begins.
