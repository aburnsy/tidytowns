## Description

Set up a deliberate four-season photography sweep of the village's key spots so that the next application has spring, summer, autumn and winter coverage of the same locations side by side. The 2026 application leans heavily on the photos we already had on hand, which skews toward May 2026 and a handful of earlier moments. A planned seasonal sweep would give us:

- The same vantage point at the monument, sensory garden, church grounds, cemetery, Bog Walk, Old Road Triangle, and each estate entrance, repeated across four seasons.
- Pollinator activity captured at peak (early spring crocus, late spring allium, summer wildflower verges, autumn seedheads).
- Bog Walk seasonal contrast (wet-bog summer cotton, autumn colour, winter standing dead stems).

## Approach

- Pick the 12 to 15 key spots in advance with named compass bearings so successive photos line up.
- One half-day per season, ideally same weather conditions where possible.
- Photos uploaded directly to the public tracker so they slot into the existing `place_photos` macros without renaming.

## Why this is a project on its own

The 2026 application is built on the photos we had. Trying to manufacture seasonal coverage retroactively in a single year doesn't work. Treating it as its own multi-season project makes it the workstream it actually is.
