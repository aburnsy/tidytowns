## Description

A formal heritage trail connecting the Norman castle, the old forge, the church, and the bog walk entrance would create a coherent visitor experience and showcase the village's rich history. A central map and wayfinding signs tie the individual sites into a unified trail. Adjudicators have specifically praised this kind of heritage trail — built around a central interpretive map — as an effective way to showcase a village's history.
